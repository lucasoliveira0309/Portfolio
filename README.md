# Lucas.dev — Portfólio Pessoal 🚀

Bem-vindo ao repositório do meu portfólio pessoal! Este projeto foi desenvolvido para apresentar minha trajetória, minhas habilidades como desenvolvedor e os projetos nos quais venho trabalhando. 

---

## ✨ Funcionalidades e Diferenciais

* **Design Responsivo:** Totalmente adaptável para dispositivos móveis (smartphones, tablets e desktops) utilizando um menu *drawer* lateral no mobile.
* **Partículas em Canvas (Fundo):** Um efeito visual leve de partículas flutuantes conectadas pelo mouse, criado com a API Canvas do HTML5 nativo.
* **Cursor Customizado:** Um cursor estilizado e interativo que reage ao passar o mouse sobre links e botões.
* **Scroll Suave Customizado:** Navegação "smooth" com aceleração matemática (Easing) entre as seções, garantindo fluidez premium.
* **Revelação ao Rolar (Scroll Reveal):** Elementos surgem suavemente na tela usando o `IntersectionObserver`, otimizando a performance em relação a eventos de scroll tradicionais.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído **sem o uso de frameworks complexos**, provando o domínio das bases do desenvolvimento web:

* **HTML5:** Estruturação semântica.
* **CSS3:** Variáveis nativas (`:root`), Flexbox, CSS Grid, Animações (`@keyframes`), Efeitos de vidro (`backdrop-filter`) e media queries.
* **JavaScript (Vanilla):** Lógica para animação no Canvas, delegação de eventos, manipulação de classes para o menu e rolagem suave customizada.
